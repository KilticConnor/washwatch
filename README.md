# WashWatch

A tiny phone-first PWA for timing car-wash queue throughput.

## Publish with GitHub Pages
1. Create a new public GitHub repository named `washwatch`.
2. Upload **the contents of this folder** to the root of the repository.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. GitHub will show the published Pages URL after deployment.
8. Open that URL in Safari on the iPhone.
9. Tap **Share → Add to Home Screen → Add**.

Your timing history is stored locally on that device/browser. Use Export Backup occasionally.

## Files
- index.html — application
- manifest.webmanifest — install metadata
- sw.js — offline cache/service worker
- icon-192.png / icon-512.png — app icons
